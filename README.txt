Project Purpose

The Week 9 Loops and Arrays project consists of two Visual Basic .NET applications that demonstrate the use of arrays and loop structures. The assignment also includes a reflection, query log, screenshots, and GitHub documentation to show the development process completed during Weeks 6–8.

- Pathway A (Console Application)
- Pathway B (WPF Application)

- README.txt

Week 9 Improvements

This assignment builds on previous weeks by introducing:

- Arrays
- For...Next loops
- For Each loops
- Do...Loop
- While loops
- Reflection on the Weeks 6–8 development process
- GitHub repository organization and documentation

How to Run

Pathway A
1. Open the Console Application project in Visual Studio 2022.
2. Run the application.
3. Test the menu options and loop behavior.
4. Exit the program.

Pathway B
1. Open the WPF project in Visual Studio 2022.
2. Run the application.
3. Click the Loop button to display the loop output.
4. Click the Clear button to clear the displayed information.
