# Project Overview

The Week 9 Loops and Arrays project consists of two Visual Basic .NET applications developed for my Application Development course.

The purpose of this assignment is to demonstrate the use of arrays and loop structures while reflecting on the development process completed during Weeks 6–8. This assignment also reinforces documentation, testing, GitHub organization, and following both written instructions and a video tutorial.

Week 9 introduces arrays, For...Next loops, For Each loops, Do...Loop structures, and While loops. It also required completing both a starter code project and a video tutorial project, then making a small personal customization.

---

# Repository Guide

This repository contains all files required for the Week 9 assignment.

## Source Code

The main Visual Studio project files are organized into two project folders.

### Pathway A

The **Pathway A** folder contains the Visual Basic Console Application created from the Week 9 starter code.

The project demonstrates:

- Arrays
- For...Next loops
- Do...Loop
- For Each loops
- Menu selections
- User input

### Pathway B

The **Pathway B** folder contains the Visual Basic WPF application completed by following the required Week 9 video tutorial.

The project demonstrates:

- While loops
- For Each loops
- Buttons
- TextBox output
- ListBox output

For my personal customization, I changed the application title to **Ever After Cafe** and modified the loop output to display **Table1 through Table10** instead of simple numbers.

# How to Run

### Pathway A

1. Open the Pathway A solution in Visual Studio 2022.
2. Build and run the Console Application.
3. Test the menu options and loop behavior.
4. Exit the application.

### Pathway B

1. Open the Pathway B solution in Visual Studio 2022.
2. Build and run the WPF application.
3. Click the **Loop** button to display the loop output.
4. Click the **Clear** button to remove the displayed information.
